# Fallback-first Mamba (AGENTS.md constraint 4):

# Usage: pip install -r requirements-colab.txt
#
# Pin policy: modern versions are fine. torch / transformers / numpy use
# FLOOR pins (>=) because Colab ships newer versions already; strict pins
# would force a multi-GB torch re-download and a numpy downgrade on every
# fresh VM session. Other deps are unpinned and resolve to whatever Colab
# ships. The package itself (pyproject.toml) mirrors these floor pins.
